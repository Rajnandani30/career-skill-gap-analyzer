# CareerAI — AI-Powered Career Readiness & Skill Gap Analyzer

CareerAI is an AI-enabled full stack web application that analyzes a user's skills and compares them with the requirements of a target job role.

## Features

- User registration and login
- Resume/skill input
- Job description analysis
- AI-powered skill extraction
- Skill matching
- Skill gap identification
- Career readiness score
- Personalized learning roadmap
- AI-powered interview preparation
- Analysis history
- Responsive dashboard

## Technologies

- HTML
- CSS
- Bootstrap
- React JS
- Node.js
- Express.js
- MongoDB
- REST APIs
- jQuery Mobile
- AI/LLM API
- Git & GitHub

## Project Goal

The goal of CareerAI is to help students and job seekers understand their current career readiness, identify missing skills, and receive a personalized roadmap for reaching their target job role.
